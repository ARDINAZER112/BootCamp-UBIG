# Episode 07 - Float

`float: left|right` mengambang elemen ke sisi dan teks mengelilinginya.
- Dulu dipakai untuk layout kolom; sekarang gunakan flex/grid. Float tetap berguna untuk gambar dengan teks.
- Parent bisa "kolaps" (tinggi 0) → atasi dengan **clearfix** atau `display: flow-root`.
- `clear: both` menghentikan efek float.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
