# 20 - ReactJS Tutorial - 20 - Styling and CSS Basics

Empat cara styling dasar:
1. CSS stylesheet biasa (`import "./app.css"`)
2. Inline style (objek, properti camelCase)
3. CSS Modules (`style.module.css`, nama class ter-scope)
4. Class dinamis lewat template string

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Isi `src/`

- `App.jsx`
- `Modul.jsx`
- `Styled.jsx`
- `app.css`
- `modul.module.css`
- `main.jsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
