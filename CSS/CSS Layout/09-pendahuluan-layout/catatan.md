# Episode 09 - Pendahuluan Layout

Tiga pendekatan lebar layout, lalu teknik modern:
1. **Fixed width** — lebar tetap (px)
2. **Liquid/fluid** — lebar fleksibel (%)
3. **Responsive** — menyesuaikan perangkat (media query, grid, flex)
Lihat `index.html` untuk perbandingan tiga lebar sekaligus.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
