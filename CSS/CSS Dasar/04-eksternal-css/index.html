# Episode 04 - Eksternal CSS

Eksternal CSS = file .css terpisah, dihubungkan dengan <link rel="stylesheet" href="style.css"> di <head>.

  • - Cara terbaik, untuk proyek nyata: satu file bisa dipakai banyak halaman, rapi, mudah dirawat, bisa di-cache browser.
  • - Lihat index.html dan halaman2.html memakaistyle.css yang sama.
