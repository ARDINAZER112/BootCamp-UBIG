# Episode 17 - IF Statement (Percabangan)

`if (kondisi) { ... } else { ... }` menjalankan kode sesuai kondisi.
Kondisi dikonversi ke boolean (truthy/falsy). Tanda kurung kurawal boleh dihilangkan untuk satu baris, tapi sebaiknya selalu dipakai.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
