# Episode 16 - Border

- Shorthand: `border: 2px solid #333;` (width style color)
- Style: solid, dashed, dotted, double, groove… · Per sisi: `border-top`, `border-left-color`
- `border-radius` (sudut membulat, `50%` = lingkaran) · `outline` (di luar border, tidak memengaruhi layout)

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
