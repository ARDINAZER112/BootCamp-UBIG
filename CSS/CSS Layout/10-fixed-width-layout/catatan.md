# Episode 10 - Fixed Width Layout

Lebar halaman dikunci (mis. 960px) dan dipusatkan dengan `margin: 0 auto`.
- Kelebihan: mudah dikontrol. Kekurangan: muncul scroll horizontal di layar kecil, ruang kosong di layar besar.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
