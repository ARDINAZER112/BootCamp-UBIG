# Episode 04 - Variabel (let, var, const)

Variabel = wadah untuk menyimpan nilai.
- `let` — bisa diubah, block-scoped (disarankan)
- `const` — tidak bisa di-assign ulang, block-scoped (default terbaik)
- `var` — cara lama, function-scoped dan di-hoist (hindari)
Aturan nama: huruf/angka/_/$, tidak diawali angka, peka huruf besar-kecil, gunakan camelCase.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
