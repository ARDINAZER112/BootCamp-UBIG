# Episode 11 - NaN dan Undefined

- `undefined`: variabel dideklarasikan tapi belum diberi nilai / properti tidak ada / fungsi tanpa return.
- `null`: nilai kosong yang **sengaja** ditetapkan.
- `NaN` (Not a Number): hasil operasi numerik tidak valid. `NaN !== NaN`, cek dengan `Number.isNaN()`.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
