# Episode 15 - Responsive Layout - Media Queries

Media query menerapkan CSS hanya jika kondisi terpenuhi:
`@media (max-width: 768px) { ... }` · `(min-width: 768px)` · `(orientation: landscape)` · `(prefers-color-scheme: dark)` · `print`
- **Mobile-first:** tulis gaya dasar untuk HP, lalu tambah `min-width` untuk layar lebih besar (disarankan).
- Breakpoint umum: 600px (HP), 768px (tablet), 1024px (laptop), 1200px (desktop).
Ubah ukuran jendela dan perhatikan warna latar berubah.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
