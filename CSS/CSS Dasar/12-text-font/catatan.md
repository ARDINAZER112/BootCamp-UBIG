# Episode 12 - Text: Font Family, Size, Weight, Style & Decoration

- `font-family: "Poppins", Arial, sans-serif;` (daftar fallback)
- `font-size`: px, em, rem, % · `font-weight`: 100–900 / bold · `font-style`: italic
- `text-decoration`: underline, line-through, none (+ warna & style)
- Shorthand: `font: italic bold 16px/1.5 Arial, sans-serif;`

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
