# Belajar Laravel 12 per Episode

Setiap folder = 1 episode dari playlist Laravel 12 di Google Drive.
Di dalam folder ada `README.md` (ringkasan materi) dan file contoh kode.

Proyek contoh: **tokoku**, toko dengan produk dan kategori. Episode 5–20 saling menyambung
dan membangun satu aplikasi CRUD yang sama.

## Persiapan

- PHP 8.2+ dan Composer
- MySQL (misalnya XAMPP) atau SQLite
- Node.js (opsional)

```bash
composer create-project laravel/laravel tokoku
cd tokoku
php artisan serve
```

## Alur belajar

| Episode | Topik |
|---|---|
| 01–02 | Instalasi, struktur folder, konfigurasi |
| 03–04 | Routing, view, Blade |
| 05–06 | Controller, model, MVC |
| 07–08 | Migration, seeder, factory |
| 09–15 | CRUD: read, create, validasi, detail, update, delete, search |
| 16 | Resource controller (CRUD lengkap) |
| 17 | Relasi dan join |
| 18 | Template admin |
| 19 | Upload gambar |
| 20 | QR Code dan Barcode |
