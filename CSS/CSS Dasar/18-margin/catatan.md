# Episode 18 - Margin

Margin = jarak **di luar** border, antar elemen. Sintaks sama dengan padding.
- `margin: 0 auto;` + `width` → memusatkan blok secara horizontal.
- **Margin collapsing:** margin vertikal antar blok yang bersebelahan digabung (diambil yang terbesar).
- Margin boleh negatif.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
