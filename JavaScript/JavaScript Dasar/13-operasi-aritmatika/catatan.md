# Episode 13 - Operasi Aritmatika

Operator: `+ - * / % **`, increment `++`, decrement `--`.
Assignment: `= += -= *= /= %= **=`.
Prioritas: `()` → `**` → `* / %` → `+ -`. Perhatikan `"5" + 3` = `"53"` (string), tapi `"5" - 3` = `2`.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
