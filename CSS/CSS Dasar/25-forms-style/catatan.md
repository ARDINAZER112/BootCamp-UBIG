# Episode 25 - Forms Style

- Style `input`, `select`, `textarea`, `button`; atur `padding`, `border`, `border-radius`, `width`.
- `:focus` (saat aktif), `:disabled`, `:valid/:invalid`, `::placeholder`
- Pakai `outline: none` hanya jika menggantinya dengan indikator fokus lain (aksesibilitas).
- Selector atribut: `input[type="text"]`.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
