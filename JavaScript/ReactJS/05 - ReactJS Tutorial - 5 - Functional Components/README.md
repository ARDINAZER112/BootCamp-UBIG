# 05 - ReactJS Tutorial - 5 - Functional Components

Functional component adalah fungsi JavaScript yang mengembalikan JSX.
Lebih ringkas dibanding class, dan sekarang menjadi cara standar.
Nama komponen harus diawali huruf kapital.

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Isi `src/`

- `App.jsx`
- `Greet.jsx`
- `main.jsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
