# 07 - ReactJS Tutorial - 7 - Hooks Update

Sejak React 16.8, **hooks** memungkinkan functional component punya state dan lifecycle.
Karena itu class component tidak lagi wajib. Kita tetap mempelajari class supaya bisa membaca kode lama.
Hooks dibahas lengkap di seri "React Hooks Tutorial" (episode 44–76).

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Isi `src/`

- `App.jsx`
- `HookPertama.jsx`
- `main.jsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
