# Episode 18 - Else IF & Switch Case

- `else if` untuk banyak kondisi berurutan (pertama yang benar dieksekusi).
- `switch` cocok untuk membandingkan **satu nilai** dengan banyak kasus (memakai `===`). Jangan lupa `break`, dan `default`.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
