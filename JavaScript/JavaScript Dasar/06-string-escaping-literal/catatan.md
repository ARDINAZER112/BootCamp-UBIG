# Episode 06 - String (Escaping & Literal)

String ditulis dengan `'...'`, `"..."`, atau template literal `` `...` ``.
Escape character: `\n` (baris baru), `\t` (tab), `\\` (backslash), `\'` `\"` (tanda kutip).
Template literal mendukung multiline dan interpolasi `${...}`.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
