# Episode 08 - Latihan Multi Kolom

Latihan layout 3 kolom klasik (sidebar kiri – konten – sidebar kanan) dengan header dan footer.
Versi di sini memakai **float** (cara lama, sesuai urutan materi) dan versi **flex** sebagai pembanding.
Buka `float.html` dan `flex.html`.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
