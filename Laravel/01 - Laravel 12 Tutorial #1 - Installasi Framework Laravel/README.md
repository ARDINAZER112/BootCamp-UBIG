# 01 - Laravel 12 Tutorial #1 - Installasi Framework Laravel

Laravel adalah framework PHP dengan pola **MVC** (Model, View, Controller).

**Kebutuhan**
- PHP 8.2 atau lebih baru
- Composer
- Database (MySQL via XAMPP, atau SQLite bawaan)
- Node.js (opsional, untuk Vite)

**Langkah**
1. Buat proyek dengan Composer (atau Laravel Installer).
2. Masuk ke folder proyek.
3. Jalankan server pengembangan.
4. Buka `http://127.0.0.1:8000`.

Proyek contoh di seluruh seri ini bernama **tokoku** (toko dengan produk dan kategori).

## File di folder ini

- `perintah.sh`
- `.env.contoh`
