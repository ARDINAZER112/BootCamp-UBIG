# Episode 05 - Tipe Data

Tipe primitif: `string`, `number`, `boolean`, `undefined`, `null`, `bigint`, `symbol`.
Tipe referensi: `object` (termasuk array dan function).
Cek tipe dengan `typeof`. JS bersifat **dynamically typed** (tipe ada pada nilai, bukan variabel).

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
