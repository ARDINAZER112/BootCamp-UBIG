# Episode 07 - New String Methods

Method baru di ES6 (dan sesudahnya) untuk string:
`startsWith()`, `endsWith()`, `includes()`, `repeat()`, `padStart()`/`padEnd()` (ES2017), `trimStart()`/`trimEnd()` (ES2019), `replaceAll()` (ES2021), `at()` (ES2022).

**Cara pakai:** `node script.js` (atau tempel ke Console browser F12). Ubah kodenya lalu jalankan ulang.
