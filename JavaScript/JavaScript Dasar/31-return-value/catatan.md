# Episode 31 - Return Value

`return` mengembalikan nilai dan **menghentikan** fungsi. Tanpa return → `undefined`.
Fungsi bisa mengembalikan nilai apa pun (angka, string, array, objek, fungsi). Untuk banyak nilai, kembalikan array/objek.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
