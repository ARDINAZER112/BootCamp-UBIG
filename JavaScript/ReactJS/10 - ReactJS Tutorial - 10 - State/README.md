# 10 - ReactJS Tutorial - 10 - State

State adalah data milik komponen yang bisa berubah. Saat state berubah, komponen di-render ulang.
Beda dengan props: props datang dari luar (read-only), state dikelola di dalam komponen.

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Isi `src/`

- `App.jsx`
- `Message.jsx`
- `main.jsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
