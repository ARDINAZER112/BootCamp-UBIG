# Episode 09 - Tipe Data Number

Number mencakup bilangan bulat & desimal (floating point 64-bit).
- Nilai khusus: `Infinity`, `-Infinity`, `NaN`
- Batas aman: `Number.MAX_SAFE_INTEGER`
- Konversi: `Number("42")`, `parseInt("42px")`, `parseFloat("3.14")`
- Format: `toFixed(2)`, `toString(2)` · Library `Math`: `round`, `floor`, `ceil`, `random`, `max`, `min`, `abs`, `pow`, `sqrt`

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
