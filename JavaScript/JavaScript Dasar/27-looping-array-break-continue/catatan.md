# Episode 27 - Looping Array, Break dan Continue

- Loop array: `for` biasa, `for...of`, `forEach`, `entries()`.
- `break` → keluar dari loop; `continue` → lompat ke iterasi berikutnya.
- Label untuk keluar dari loop bersarang.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
