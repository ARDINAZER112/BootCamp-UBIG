# Episode 23 - Array Part 3 - Method Lanjutan

Method higher-order (menerima fungsi) yang tidak mengubah array asli:
`map` (transformasi), `filter` (saring), `reduce` (ringkas jadi satu nilai), `find`/`findIndex`, `some`/`every`, `forEach`, `sort`, `reverse`.
`sort()` default mengurutkan sebagai **string** → beri fungsi pembanding untuk angka.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
