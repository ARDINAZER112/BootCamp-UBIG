# Episode 02 - Instalasi Chrome dan VSCode

Alat yang dibutuhkan:
1. **Google Chrome** — browser + DevTools (F12 → tab Console/Elements/Sources)
2. **VS Code** — editor. Ekstensi yang berguna: *Live Server*, *Prettier*, *ESLint*
3. (Opsional) **Node.js** — menjalankan JS di terminal: `node script.js`
Langkah: buat folder proyek → buka di VS Code → buat `index.html` + `script.js` → klik kanan *Open with Live Server*.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
