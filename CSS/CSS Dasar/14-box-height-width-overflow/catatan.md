# Episode 14 - Box, Height, Width, Overflow

- Semua elemen adalah kotak. `width`/`height` mengatur ukuran konten.
- `min-width`, `max-width` (responsif!) · satuan: px, %, vw, vh
- `overflow`: visible (default), hidden, scroll, auto — mengatur isi yang melebihi kotak.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
