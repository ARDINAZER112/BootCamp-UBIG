# Episode 25.5 - Images Style

- Responsif: `max-width: 100%; height: auto;` · `object-fit: cover|contain` (untuk gambar berukuran tetap)
- `border-radius: 50%` untuk avatar bulat · `filter: grayscale(1)`/`blur()`/`brightness()`
- Rata tengah: `display: block; margin: 0 auto;` · `float` dan teks mengelilingi gambar
- Gambar dibuat dengan SVG data-URI agar contoh bisa jalan offline.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
