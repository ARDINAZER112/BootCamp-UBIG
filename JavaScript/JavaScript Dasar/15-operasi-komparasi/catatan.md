# Episode 15 - Operasi Komparasi

Operator: `== != === !== > < >= <=`.
- `==` membandingkan nilai dengan **konversi tipe**, `===` membandingkan nilai **dan tipe** (gunakan ini).
- Objek/array dibandingkan berdasarkan **referensi**, bukan isi.
- String dibandingkan secara leksikografis.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
