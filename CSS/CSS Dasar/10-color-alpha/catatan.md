# Episode 10 - Color Alpha (Transparansi)

Alpha = tingkat transparansi (0 transparan – 1 solid).
- `rgba(0 0 0 / 0.5)`, `hsl(210 80% 50% / 0.3)`, hex 8 digit `#00000080`
- `opacity` membuat **seluruh elemen** (termasuk isi) transparan, sedangkan alpha pada warna hanya memengaruhi warna itu.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
