# 05 - Laravel 12 Tutorial #5 - Pahami Controller dan Konsep MVC dengan Mudah

**MVC**
- **Model**: data dan akses database.
- **View**: tampilan (Blade).
- **Controller**: menerima request, memanggil model, mengirim data ke view.

Controller mencegah `routes/web.php` penuh logika. Buat dengan Artisan, lalu arahkan rute ke method-nya.
Di episode ini datanya masih berupa array; dari episode 6 diganti dengan database.

## File di folder ini

- `perintah.sh`
- `ProductController.php`
- `routes-web.php`
- `products/index.blade.php`
