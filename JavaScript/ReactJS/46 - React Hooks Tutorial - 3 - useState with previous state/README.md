# 46 - React Hooks Tutorial - 3 - useState with previous state

Kalau state baru bergantung pada state lama, pakai bentuk fungsi `setState(prev => ...)`.
Ini menghindari nilai usang (stale) saat ada banyak update berturutan.

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Isi `src/`

- `App.jsx`
- `Counter.jsx`
- `main.jsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
