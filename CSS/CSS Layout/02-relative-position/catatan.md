# Episode 02 - Relative Position

`position: relative` menggeser elemen **dari posisi aslinya**, tetapi ruang aslinya tetap dipertahankan (elemen lain tidak bergeser).
- Sering dipakai sebagai **acuan (containing block)** untuk anak yang `absolute`.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
