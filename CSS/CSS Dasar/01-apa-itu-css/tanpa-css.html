# Episode 01 - Apa Itu CSS

CSS (Cascading Style Sheets) adalah bahasa untuk mengatur Tampilan HTML: warna, ukuran, jarak, tata letak, font.

  • - HTML = struktur/isi, CSS = gaya/penampilan.
  • - Sintaks: selector { properti: nilai; }
  • - Tiap pasangan properti: nilai; disebut deklarasi; semuanya dalam { } disebut rule.
  • - Bandingkan tanpa-css.html (polos) dengan index.html (sudah di-style).
