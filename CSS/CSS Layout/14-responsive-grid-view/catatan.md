# Episode 14 - Responsive Layout - Grid View

**Grid view** = layout 12 kolom yang melebar mengikuti layar (framework seperti Bootstrap memakainya).
Cara klasik: `.col-4 { width: 33.33%; }` (4/12). Cara modern: CSS Grid `repeat(12, 1fr)` dan `grid-column: span N`.
Contoh di bawah menunjukkan keduanya.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
