# Episode 10 - Sets

`Set` = koleksi nilai **unik** (tanpa duplikat), mempertahankan urutan penambahan.
Method: `add`, `has`, `delete`, `clear`, `size`, `forEach`, iterasi dengan `for...of`.
Kegunaan umum: menghapus duplikat dari array, operasi himpunan (union/irisan/selisih). Lawannya `Map` untuk pasangan kunci-nilai.

**Cara pakai:** `node script.js` (atau tempel ke Console browser F12). Ubah kodenya lalu jalankan ulang.
