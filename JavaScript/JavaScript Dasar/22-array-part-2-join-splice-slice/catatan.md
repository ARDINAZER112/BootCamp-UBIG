# Episode 22 - Array Part 2 - join, splice, slice

- `join(sep)` → gabung jadi string
- `slice(start, end)` → ambil sebagian (**tidak mengubah** array asli)
- `splice(start, hapus, ...tambah)` → hapus/sisip/ganti (**mengubah** array asli)
- `concat()` dan spread `[...a, ...b]` untuk menggabung array

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
