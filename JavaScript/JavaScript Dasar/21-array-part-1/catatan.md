# Episode 21 - Array Part 1

Array = daftar nilai berurutan dengan indeks mulai **0**.
- Buat: `[1, 2, 3]`; akses: `arr[0]`; panjang: `arr.length`; elemen terakhir: `arr[arr.length - 1]` atau `arr.at(-1)`
- Tambah/hapus: `push()`/`pop()` (ujung belakang), `unshift()`/`shift()` (depan)
- Cari: `indexOf()`, `includes()`

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
