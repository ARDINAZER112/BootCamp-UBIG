# Episode 17 - Padding

Padding = jarak **di dalam** border, antara konten dan border.
- `padding: 10px;` (semua) · `10px 20px;` (atas-bawah, kiri-kanan) · `10px 20px 30px 40px;` (atas, kanan, bawah, kiri — searah jarum jam)
- Padding menampilkan warna background elemen.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
