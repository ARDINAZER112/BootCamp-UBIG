# Episode 01 - Introduction

ES6 (ECMAScript 2015) adalah pembaruan besar JavaScript. Fitur utama yang dibahas di seri ini:
`let`/`const`, default parameter, spread, template string, method string baru, object literal enhancement, arrow function, `Set`, generator.
Ketersediaan: semua browser modern dan Node.js. Untuk browser lama dipakai transpiler (Babel).
Ringkasan sebelum/sesudah ES6 ada di `script.js`.

**Cara pakai:** `node script.js` (atau tempel ke Console browser F12). Ubah kodenya lalu jalankan ulang.
