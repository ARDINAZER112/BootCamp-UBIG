# 69 - React Hooks Tutorial - 26 - useCallback Hook

`useCallback(fn, deps)` menyimpan **referensi fungsi** antar render.
Berguna saat fungsi dioper ke child yang dibungkus `React.memo`, supaya child tidak render ulang tanpa alasan.

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

Buka **console browser** (F12) untuk melihat hasil `console.log`.

## Isi `src/`

- `App.jsx`
- `ParentComponent.jsx`
- `main.jsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
