# Episode 24 - Table Style

- `border-collapse: collapse;` agar border tabel menyatu · `padding` pada `th, td`
- Zebra: `tr:nth-child(even)` · Hover baris: `tr:hover`
- `text-align`, `vertical-align`, `caption-side`, `table-layout: fixed`

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
