# Episode 07 - Operasi String

Properti/method umum: `length`, `toUpperCase()`, `toLowerCase()`, `trim()`, `indexOf()`, `includes()`, `startsWith()`, `endsWith()`, `slice()`, `substring()`, `replace()`, `split()`, `charAt()`, `repeat()`, `padStart()`.
String itu **immutable**: method mengembalikan string baru.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
