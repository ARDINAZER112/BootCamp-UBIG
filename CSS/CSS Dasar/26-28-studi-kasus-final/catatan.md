# Episode 26-28 - Studi Kasus Final (Part 1–3: Website Portofolio)

Proyek akhir: satu halaman portofolio lengkap. `style.css` dibagi tiga bagian sesuai part:
- **Part 1:** reset, variabel, `.container`, header/navbar sticky
- **Part 2:** hero, section, kartu grid, tombol, hover
- **Part 3:** form, footer, `@media` responsif, smooth scroll
Konsep yang dipakai: box model, selector, flex, grid, variabel CSS, pseudo-class, media query.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
