# Episode 15 - Pengenalan Box Model

Setiap elemen = **content → padding → border → margin** (dari dalam ke luar).
- Default `box-sizing: content-box`: width hanya konten (padding+border ditambahkan).
- Disarankan `box-sizing: border-box` agar width sudah termasuk padding+border.
Bandingkan dua kotak di contoh: sama-sama `width: 200px`, tapi ukuran akhirnya beda.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
