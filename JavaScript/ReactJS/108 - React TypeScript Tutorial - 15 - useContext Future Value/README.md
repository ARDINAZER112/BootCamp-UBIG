# 108 - React TypeScript Tutorial - 15 - useContext Future Value

Kalau nilai context baru tersedia nanti (misalnya data user setelah login), tipenya dibuat
`UserContextType | null` dan nilai awalnya `null`. Pengguna context harus mengecek `null`.

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

Pemeriksaan tipe: `npm run typecheck`

## Isi `src/`

- `App.tsx`
- `User.tsx`
- `UserContext.tsx`
- `main.tsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
