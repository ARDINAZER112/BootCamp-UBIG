# Episode 08 - Inheritance

Sebagian properti **diwariskan** dari parent ke child (mis. `color`, `font-*`, `line-height`, `text-align`).
Properti box (`border`, `margin`, `padding`, `background`) **tidak** diwariskan.
Pakai nilai `inherit` untuk memaksa mewarisi, `initial` untuk reset, `unset` otomatis.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
