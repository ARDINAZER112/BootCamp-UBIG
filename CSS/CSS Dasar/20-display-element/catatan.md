# Episode 20 - Display Element

- `block`: mulai baris baru, selebar parent (div, p, h1) · `inline`: sebaris, width/height/margin vertikal tidak berlaku (span, a)
- `inline-block`: sebaris tapi bisa diatur ukuran · `none`: hilang total (beda dengan `visibility: hidden` yang masih memakan ruang)
- `flex` dan `grid`: sistem layout modern.

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
