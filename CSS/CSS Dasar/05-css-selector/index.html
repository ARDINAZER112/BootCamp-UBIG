# Episode 05 - CSS Selector

Selector menentukan elemen mana yang di-style.

  • - Elemen: p {} · Class: .kartu {} · ID: #judul {} (ID unik, class boleh banyak)
  • - Universal: * {} · Grup: h1, h2 {}
  • - Descendant: div p {} · Child: div > p {} · Adjacent: h1 + p {} · Sibling: h1 ~ p {}
  • - Atribut: a[target="_blank"] {} · Pseudo-class: a:hover, li:first-child, li:nth-child(2n) · Pseudo-element: p::first-line, ::before
