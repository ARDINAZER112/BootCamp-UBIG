# Episode 10 - Boolean

Boolean: `true` / `false`.
**Falsy** (dianggap false): `false`, `0`, `-0`, `""`, `null`, `undefined`, `NaN`. Selain itu **truthy** (termasuk `"0"`, `[]`, `{}`).
Konversi: `Boolean(x)` atau `!!x`.

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
