# Episode 03 - Menjalankan JavaScript

Cara menjalankan JS:
1. **Inline** di HTML: `<script>...</script>`
2. **Eksternal:** `<script src="script.js"></script>` (disarankan, taruh sebelum `</body>` atau pakai `defer`)
3. **Console browser** (F12)
4. **Node.js** di terminal
Output: `console.log()`, `alert()`, `document.write()`, atau ubah elemen HTML.

**Cara pakai:** Buka `index.html` di browser (atau Live Server).
