# Bonus - Flexbox

Flexbox = layout 1 dimensi (baris atau kolom). Tidak ada di folder, tapi melengkapi Grid.
- Container: `display: flex`, `flex-direction`, `justify-content` (sumbu utama), `align-items` (sumbu silang), `gap`, `flex-wrap`
- Item: `flex: grow shrink basis`, `align-self`, `order`
- **Flex vs Grid:** flex untuk komponen satu arah (navbar, deretan tombol); grid untuk layout halaman dua dimensi.
