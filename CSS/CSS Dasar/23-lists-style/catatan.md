# Episode 23 - Lists Style

- `list-style-type`: disc, circle, square, decimal, lower-alpha, none · `list-style-position`: inside/outside
- `list-style-image: url(...)` · shorthand `list-style`
- Hapus bullet untuk navbar: `list-style: none; padding: 0;`
- Custom bullet: `li::marker { color: red; }`

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
