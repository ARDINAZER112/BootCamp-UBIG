# Episode 04 - Fixed Position

`position: fixed` memposisikan elemen relatif ke **viewport** dan tetap di tempat saat halaman di-scroll.
- Cocok untuk navbar atas, tombol "kembali ke atas", chat bubble.
- Karena keluar dari alur, beri `padding-top` pada body agar konten tidak tertutup.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
