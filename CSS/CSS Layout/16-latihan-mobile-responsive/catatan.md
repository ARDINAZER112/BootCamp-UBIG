# Episode 16 - Latihan Mobile Responsive Layout

Latihan akhir: halaman responsif mobile-first dengan navbar (menu bertumpuk di HP, horizontal di desktop), hero, grid kartu 1/2/3 kolom, sidebar yang pindah ke bawah, dan footer.
**Tantangan:** tambah tombol hamburger dengan JavaScript untuk membuka/menutup menu di HP.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
