# Episode 03 - Absolute Position

`position: absolute` mengeluarkan elemen dari alur normal; ia diposisikan relatif terhadap **ancestor terdekat yang position-nya bukan static** (jika tidak ada, relatif ke halaman).
- Elemen lain bertingkah seolah elemen ini tidak ada.
- Pola umum: parent `relative` + anak `absolute` (badge, ikon, overlay).

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
