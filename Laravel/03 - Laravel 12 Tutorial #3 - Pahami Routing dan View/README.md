# 03 - Laravel 12 Tutorial #3 - Pahami Routing dan View

Routing menghubungkan URL ke aksi (closure, view, atau controller). Rute web ada di `routes/web.php`.

Yang dibahas: `Route::get`, `Route::view`, parameter rute (wajib/opsional), constraint (`whereNumber`), nama rute (`->name()`), group dengan prefix, dan fallback 404.
View ada di `resources/views` dan ditulis dengan Blade (`nama.blade.php`).

## File di folder ini

- `routes-web.php`
- `tentang.blade.php`
- `profil.blade.php`
- `perintah.sh`
