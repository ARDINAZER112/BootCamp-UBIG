# Episode 08 - Object Literal Enhancements

Penyederhanaan penulisan objek:
1. **Shorthand properti:** `{ x, y }` ganti `{ x: x, y: y }`
2. **Shorthand method:** `{ sapa() {} }` ganti `{ sapa: function() {} }`
3. **Computed property:** `{ [ekspresi]: nilai }`
Bonus terkait: destructuring objek `const { a, b } = obj`.

**Cara pakai:** `node script.js` (atau tempel ke Console browser F12). Ubah kodenya lalu jalankan ulang.
