# 111 - React TypeScript Tutorial - 18 - Component Prop

Props yang berupa **komponen**: bertipe `React.ComponentType<Props>` (menerima komponen) atau
`React.ReactNode` (menerima elemen yang sudah jadi).

## Menjalankan proyek ini

Butuh Node.js 18 atau lebih baru.

```bash
npm install
npm run dev
```

Lalu buka alamat yang tampil di terminal (biasanya http://localhost:5173).

Pemeriksaan tipe: `npm run typecheck`

## Isi `src/`

- `App.tsx`
- `Login.tsx`
- `Private.tsx`
- `Profile.tsx`
- `main.tsx` (titik masuk), `index.css`

_Catatan: StrictMode sengaja tidak dipakai di `main`, supaya log lifecycle dan render tidak ganda._
