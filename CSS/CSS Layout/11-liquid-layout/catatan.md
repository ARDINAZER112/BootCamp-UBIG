# Episode 11 - Liquid Layout

Lebar memakai **persentase** sehingga ikut mengecil/membesar mengikuti jendela.
- Tambahkan `min-width`/`max-width` supaya tidak terlalu sempit/lebar.
- `box-sizing: border-box` penting agar padding tidak membuat total lebar >100%.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
