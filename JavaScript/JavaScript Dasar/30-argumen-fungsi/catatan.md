# Episode 30 - Argumen Fungsi

- **Parameter** = nama di definisi; **argumen** = nilai saat memanggil.
- Argumen yang tidak diberikan → `undefined`.
- Nilai default: `function f(a, b = 10)`.
- Banyak argumen: rest parameter `...args`; objek `arguments` (cara lama).

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
