# Episode 01 - Apa itu JavaScript?

JavaScript = bahasa pemrograman yang membuat web **interaktif**.
- HTML = struktur, CSS = tampilan, **JS = perilaku**.
- Berjalan di browser (dan di server/desktop lewat Node.js).
- Standar bahasanya bernama ECMAScript (ES6/ES2015 dst).
Jalankan: `node script.js` atau buka `index.html` dan lihat Console (F12).

**Cara pakai:** Buka `index.html` di browser (atau Live Server).
