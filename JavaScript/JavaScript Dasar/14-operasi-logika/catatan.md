# Episode 14 - Operasi Logika

- `&&` (AND), `||` (OR), `!` (NOT)
- **Short-circuit:** `a && b` berhenti di `a` jika falsy; `a || b` berhenti di `a` jika truthy.
- Nullish coalescing `??` hanya mengganti `null/undefined` (bukan 0 atau "").

**Cara pakai:** Jalankan: `node script.js` (atau tempel ke Console browser F12).
