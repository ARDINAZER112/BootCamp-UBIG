# Episode 01 - Pendahuluan Position

Properti `position` menentukan cara elemen diposisikan. Nilainya:
`static` (default), `relative`, `absolute`, `fixed`, `sticky`.
- `top`, `right`, `bottom`, `left` baru berfungsi jika position **bukan static**.
- `static` mengikuti alur normal dokumen; top/left diabaikan.

**Cara pakai:** buka `index.html` di browser, ubah CSS lalu refresh. Untuk materi responsif, kecilkan jendela browser atau pakai DevTools (F12) → mode device.
