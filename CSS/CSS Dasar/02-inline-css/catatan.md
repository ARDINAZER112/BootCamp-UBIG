# Episode 02 - Inline CSS

Inline CSS ditulis langsung di atribut `style` pada elemen.
- Cocok untuk perubahan cepat/satu elemen saja.
- **Kekurangan:** sulit dirawat, tidak bisa dipakai ulang, prioritasnya paling tinggi (sulit di-override).
- Format: `<p style="color: red; font-size: 20px;">`

**Cara pakai:** buka `index.html` di browser, lalu ubah CSS dan refresh.
