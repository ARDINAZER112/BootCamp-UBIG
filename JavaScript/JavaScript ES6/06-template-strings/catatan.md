# Episode 06 - Template Strings

Template literal memakai backtick `` ` ``:
- Interpolasi: `${ekspresi}`
- Multiline tanpa `\n`
- **Tagged template:** `tag\`teks ${x}\`` memanggil fungsi `tag` (dipakai styled-components, i18n, dll.).

**Cara pakai:** `node script.js` (atau tempel ke Console browser F12). Ubah kodenya lalu jalankan ulang.
